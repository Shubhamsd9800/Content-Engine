Four limits that shape every step

No view counts. Instagram exposes none through any free route. engagement = likes + comments — a proxy, and it is never called reach, in any file or any post.
Twelve posts per run. --limit does not raise it. The accumulating metrics.csv is the fix, not a flag.
No post URLs from any read command. All 23 checked. Step A6 is manual by design — it is not a bug to be engineered away.
No finished post. New audience arrives daily and old posts keep collecting — a post is finished only from the creator's side. So no age correction is applied; selection is top 3 by rank, which needs no cutoff, and metrics.csv accumulates so a late riser is picked up on a later run.
