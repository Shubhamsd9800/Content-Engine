   **Or if you don't even want to comment, I'm just going to give you the link right here.
   Just go here. It's public.**"

→ **NAME IT: THE WAIVED GATE.** He offers the gate, then immediately removes it — in the same

comment-to-DM gate. `swipe.md` rejects it on the grounds that at zero followers there is

| | |
|---|---|
| **What it keeps** | everyone who comments still comments. The automation still fires. |
| **What it removes** | the transactional read. Nobody feels taxed for a resource. |
| **What it buys at zero followers** | **the resource actually reaches people.** A gated link with no audience reaches nobody; a public link reaches whoever watched. |
| **What it costs** | some comment volume — which is the metric that matters least here. |

**This is the version of the gate that works before an audience exists**, and it comes from the
account with the highest gate volume on the watchlist. ⚠️ **One sighting, one account. A strong
hypothesis, not a finding.**

WHAT TO STEAL  1. **THE WAIVED GATE.** Ask for the comment, then give the link anyway.
               2. **THE ANNOUNCED GIVE** in sentence two — state the price before spending
                  the viewer's attention.
               3. **THE VERIFICATION BEAT** — end by showing the result exists, live.
