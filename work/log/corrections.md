# corrections.md — every time a draft got it wrong

**This is how the engine learns.** A correction made only in conversation recurs next week.

```
## <yyyy-mm-dd> — <one-line label>
Skill:      which skill produced it
Wrote:      what the draft said
Changed to: what Shubham changed it to
Why:        the reason, in his words if possible
Class:      voice | structure | claim | audience | format | hook
Fix:        what changed in which file — or "watching, not fixing yet"
```

**Do not fix a skill on one occurrence.** One correction is taste. **Two of the same class
is a bug in the skill** — rewrite the skill file, don't patch the draft.
